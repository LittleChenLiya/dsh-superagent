# 超级智能体

长周期自主执行插件：给出一个目标，它把目标拆成可并行的子任务，交给 worker 执行，最后合并成一份报告。进程重启后仍能从断点继续，不必从头再来。

## 它解决什么问题

- **你的事横跨好几个领域，管会话比干活还累。** 代码、文档、数据、网页上的操作，各自都要开会话、记进度、接上下文，一多就乱，还容易忘掉上次做到哪。这个插件当一个调度台用：你说清要什么结果，它拆活、并行、盯进度、最后汇总；你只管下命令、做关键判断、验收结果，不必操心对话里的细枝末节。
- **目标大，一步做不完。** 把一句话目标拆成有依赖关系的子任务，按计划推进，而不是把所有事塞进一次对话。
- **串行太慢。** 互不依赖的子任务并行执行，各自在自己的工作区里干活，互不覆盖。
- **中途会断。** 计划、进度和已产出的文件都落盘；宿主重启或对话结束之后可以继续。
- **结果要能核对。** 每个子任务都留下状态、用量和成本，最后合并成一份可读的报告，失败和遗漏不会被悄悄吞掉。

## 安装

桌面应用的「添加插件」对话框接受三种输入，任选一种：

1. **包名**：`@xiangyixie/dsh-superagent@0.25.0`
2. **GitHub 仓库**：`https://github.com/LittleChenLiya/dsh-superagent`
3. **本地目录**：`file:` 加上插件目录的绝对路径

也可以从「发现」页添加插件索引，然后一键安装：

```
https://raw.githubusercontent.com/LittleChenLiya/dsh-superagent/main/plugin-index.json
```

升级时是**先卸载再装新版**。同一个 profile 里的其他插件也要先卸载，再装它们的新版；不要让对话框直接覆盖。

## 需要命令执行能力时

worker 默认只做规划与读写；如果要让它运行命令、构建或测试，请开启 `commandWorkerPermission`。不开也能用，但涉及命令的步骤会被拦下。

## 安全与成本

- 不可逆操作、文件上传和域名访问都受策略约束，可随时停止。
- 成本按配置的价目表估算；没有价目的模型明确标成 `unpriced`，不会显示成 0。多币种分别合计，不跨币种相加。

完整的命令、配置和设计说明见 [README](https://github.com/LittleChenLiya/dsh-superagent#readme)。
