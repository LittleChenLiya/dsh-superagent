# Superagent 能力路线图

> 记录日期：2026-11-25  
> 适用版本：`@xiangyixie/dsh-superagent` 0.25.0 之后  
> 产品决策：**只保留一个全局助理，不设置项目助理。** 工作区只是任务执行范围，不是独立助理身份。

## 1. 产品定位

把一个目标交给 Superagent，它负责规划、并行执行、验收、汇总和沉淀产物。用户始终只与一个全局助理沟通，不需要在多个项目助理之间切换。

全局助理跨工作区理解历史任务、决定、偏好和产物；具体任务仍可绑定到一个工作区执行。

## 3. 当前基线

### 已具备，不重造

- 自动规划、子任务依赖、并行、队列、重试、取消、恢复。
- Attention 决策卡、工具审批、策略、审计轨迹。
- 跨运行记忆、用户画像、项目规则。
- 定时任务、GitHub/飞书来源事件。
- 浏览器/桌面运行时控制。
- 工作区面板、任务看板、报告、Token/成本统计。
- 原生宿主组件与主题变量集成。

### 当前短板

- 语音转写依赖浏览器麦克风权限与宿主 `remote.speech`，不可用时明确降级。
- 市场搜索需要可信注册表与固定公钥；未配置时返回明确不可用，不伪造结果。宿主没有安装 API 时只提供已验证的安装交接与本地 Skill 导入，不自动执行第三方包安装。
- 云端 Worker 需要远端协议端点；本地不会假装已有云电脑。过期 lease 使用同 fence 的 `reattach` 续租，并从持久事件游标继续。
- MCP 新增需要宿主提供 settings 写接口；只接受 `${ENV_VAR}` 凭据引用，不保存明文密钥。
- 模型路由需要价格行显式声明角色能力；预算可在成本中心配置，无价格或无能力时明确返回无候选。
- 手机端为受限 token 的 PWA，不是独立原生 App；通过设备 SSE 实时刷新当前页。

## 4. 能力清单

### P0：下一阶段

1. **全局助理工作台**
   - 一个全局助理身份。
   - 保留工作区选择，但不再称“项目助理”。
   - 桌面端右栏默认常驻。
   - 工牌、当前工作区、模型、权限、IM 状态可见。

2. **全局产物中心**
   - 跨任务、跨工作区聚合产物。
   - 网格/列表视图。
   - 预览、下载、在原任务打开、新对话继续。
   - 搜索、类型筛选、时间筛选。
   - 后续增加分享与版本记录。

3. **主动 inbox 与每日简报**
   - 今日新增、完成、失败、需要决定、产物就绪。
   - 通知偏好、静默时段、已读状态。
   - 只聚合现有状态，不额外调用模型。

4. **跨入口连续性**
   - 先实现飞书单向回执与终态摘要。
   - 再允许授权飞书消息进入同一 Router。
   - 统一任务 ID、上下文、审批和产物。
   - 外部侧权限默认低于桌面侧。

5. **语音与多模态输入**
   - 按住说话、语音转文字。
   - 图片、PDF、Office 文件作为上下文。
   - 语音结果摘要。

6. **Skills/连接器中心**
   - MCP 添加、授权范围、健康检查。
   - Skill 导入、启停、按需加载。
   - 连接器状态与权限总览。

### P1：完整产品体验

- 持久化 Agent 档案：名称、头像、角色、模型、工具、权限、记忆范围。
- 可视化自动化规则：触发 → 动作 → 输出 → 通知 → 历史。
- 浏览器/桌面实时视图：截图流、当前动作、接管、停止。
- 记忆中心：查看、搜索、编辑、遗忘。
- 计划预览：子任务、预计成本、权限范围、运行环境。
- 质量与证据卡：测试、引用、reviewer、验收依据、置信度。

### P2：平台化

- 云端 Worker / 云电脑。
- 对外分享与协作。
- 成本中心与模型路由建议。
- 插件/技能市场。
- 手机独立 App 或 PWA。

## 5. 全局助理界面规范

### 布局

```text
宿主侧栏 | 主对话 | Superagent 工作台
```

- 宽屏：三栏，右栏默认显示。
- 中屏：主对话 + 右栏抽屉。
- 窄屏：单栏，工作台全宽覆盖。
- 使用容器查询，不只看窗口宽度。

### 主对话

- 顶部显示“全局助理”和当前工作区。
- 欢迎语与建议任务。
- 阶段卡、任务卡、审批卡、产物卡。
- 技术详情默认折叠。
- 输入框支持附件、工作区、模型、权限、语音、发送/停止。

### 工作台

1. **工牌**：名称、在线状态、全局助理身份、绑定入口。
2. **今日摘要**：新增、完成、失败、需要决定、产物就绪。
3. **待办**：审批、验收、缺能力、失败。
4. **最近任务**：状态、进度、当前阶段、耗时。
5. **工作产物**：缩略图、类型、更新时间、快捷操作。
6. **自动化记录**：最近定时/来源执行记录。

### 视觉

- 深色优先、低边框、大留白。
- 主对话可读宽度 740–840px。
- 工作台 360–420px。
- 12–16px 圆角，轻阴影。
- 状态色表达在线、运行、完成、警告。
- 使用 DSH 宿主主题变量，不写死第二套视觉语言。

## 6. 第一实施阶段

### 范围

- 移除项目助理语义，统一为全局助理。
- 右栏默认常驻并增加工牌、今日摘要、待办、最近任务、产物、自动化记录。
- 新增全局产物聚合 API。
- 产物区接入全局 API，支持搜索、筛选、预览、在原任务打开、新对话继续。
- 增加定向测试，保持现有编排器、权限、审计和存储模型不变。

### 不在本阶段

- 飞书双向聊天与写回。
- 语音输入。
- 云端 Worker。
- Skills/连接器完整管理 UI。
- 自动化规则可视化编辑器。

这些能力保留在路线图中，按后续阶段实施。

## 7. 验收标准

- 全局助理只有一个身份，工作区不作为助理角色。
- 右栏在桌面宽度默认可见，窄屏可抽屉化。
- 从派任务到查看产物不超过 3 次点击。
- 全局产物 API 不丢失原始报告 artifact，报告链接与声明产物正确去重。
- 产物路径仍受原 run 与工作区边界约束，不开放任意文件读取。
- 1440px 与 375px 无横向溢出、无按钮裁切。
- 现有全量测试通过。
- 不新增与 run store 平行的状态系统。

## 8. 后续实施顺序

1. 全局助理工作台与全局产物中心。
2. 通知偏好、每日简报与静默时段。
3. 飞书单向回执与终态摘要。
4. 授权飞书消息进入同一 Router。
5. 语音与多模态输入。
6. Skills/连接器中心。
7. 自动化规则、实时浏览器/桌面视图。
8. 云端 Worker 与跨设备实时同步。

## 9. 实施状态（2026-11-26）

- **P0 已实现**：单一全局助理、桌面常驻工作台、全局产物中心（搜索/类型/工作区/日期筛选、网格/列表、预览/下载/原任务打开/新对话续聊、跨运行版本记录）、主动 inbox 与每日简报、飞书入站与终态回执、按住说话、Router 模式附件、Skills/MCP/授权能力中心。
- **P1 已实现**：可编辑的持久全局 Agent 档案、可视化自动化规则、运行时视图、记忆中心、计划预览、质量与证据卡。候选计划由 Router 按 Digest 直接执行批准 DAG，不再经过文本重分类。
- **P2 已实现**：云端 Worker 协议与持久任务、过期 lease reattach 与事件游标恢复、安全分享与评论、成本中心与模型路由建议、签名市场与本地 Skill 导入、受限 token PWA 与设备 SSE。
- **执行闭环**：自动化 run/task/followup 均进入真实执行与终态对账；补充要求等待实际送达或错过状态；生命周期预算同时约束单次与累计用量；长目标和计划通知统一遵守事件、通道、静默时段与每小时推送偏好。
- **安全边界**：产物 realpath containment、批准计划的工具契约守卫、设备 token 最小 scope、分享 token 单次展示、市场签名与私网拦截、MCP 明文凭据拒绝、远端 lease/fencing/reattach 与幂等提交均保留。
- **验证**：全量 `1220/1221` 测试通过（1 跳过）；`check-pack` 109 个文件、82 个入口可达文件全部随包；真实 DSH 宿主完成 24 项桌面、375px 抽屉与移动 PWA 验收，包含批准计划完成执行、公开产物正文、分享撤销和移动端实时 SSE。
